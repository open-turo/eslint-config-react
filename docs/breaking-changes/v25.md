# Breaking changes in v25

This release bumps `@open-turo/eslint-config-typescript` from v23 to v24. The following breaking changes cascade from that dependency (see https://github.com/open-turo/eslint-config-typescript/blob/main/docs/breaking-changes/v24.md):

- Switches the base `eslint-plugin-perfectionist` config from `recommended-alphabetical` to `recommended-natural`, so every perfectionist rule now uses `natural` sort order (e.g. `7` sorts before `14`).
  - Removes the now-redundant per-rule `natural` overrides for `perfectionist/sort-array-includes`, `perfectionist/sort-switch-case` and `perfectionist/sort-union-types`.
- Removes the bespoke `perfectionist/sort-classes` grouping configuration (added in v21). `perfectionist/sort-classes` now inherits its groups and options from `recommended-natural`.

Most new sort-order errors can be fixed automatically with `eslint --fix`.

Additionally, `unicorn/no-array-callback-reference` is now `off` (previously `error`). This relaxes the config and will not raise new errors.
